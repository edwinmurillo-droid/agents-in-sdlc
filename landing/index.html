What ships today

The whole tab list, without the scavenger hunt.

Version 1.0.0 is a full page, not a popup. The background service worker keeps an index of every tab Chrome reports and pushes updates to the dashboard as you work.

01

Live across windows

Each tab’s title, URL, favicon, window, and last-used time stay in the index. The list updates when tabs are created, closed, changed, switched, or moved between windows.

02

Search that highlights

Filter by a substring of the title or the URL. Matches stay on screen and the matching text is marked. Clear the box to see the full list again.

03

Grouped by window

Tabs sit under the window they belong to. The one you’re in is labeled “Current window.” A checkbox on the group selects every tab in it.

04

Close, with a guardrail

Close one tab, the ones you’ve checked, or everything matching the filter. More than three tabs asks you to confirm. The dashboard tab is left out, so the tool can’t close its own page.

05

Jump back in one click

Click a row to focus that tab and bring its window forward. Last used is shown as a relative time, from “just now” through days.

06

A few voice commands

The mic listens for one English (United States) phrase through Chrome’s Web Speech API. A matching phrase fills the search box, then closes those tabs — with the same confirmation.

Voice

Say which tabs to close.

The dashboard suggests phrases like these. It is a command, not a chat. If the phrase isn’t recognized, it says so and closes nothing.

  • “close all suno tabs”
  • “close tabs matching netflix”
  • “close this window’s tabs”

How it works

Install it. Open it. Clear the pile.

  1. Install

    Add it from the Chrome Web Store

    Tab Commander 1.0.0 is free. Chrome will show the permissions it uses: tabs, windows, and storage.

  2. Open

    Click the toolbar icon

    The dashboard opens in a tab. If that tab is already open, the icon focuses it instead of making another one.

  3. Act

    Filter, select, or speak

    Close more than three tabs and it asks first. The list keeps up as tabs change — there is no refresh button.

Privacy

Your tab list stays in Chrome.

Tab Commander 1.0.0 asks Chrome for three permissions: tabs, windows, and storage. The service worker keeps an index of each tab’s id, window, title, URL, favicon, and last-accessed time in chrome.storage.local on your computer. There is no Tab Commander account and no Tab Commander server receiving that index.

Voice commands use the browser’s Web Speech API, set to English (United States). In Chrome, speech recognition is handled by Google’s service, so audio from the microphone can leave your device for transcription. Tab Commander does not store what you said. If that API isn’t available, the dashboard tells you voice commands need it.
